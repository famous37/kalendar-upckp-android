# Календар УПЦ КП 3.1.0 RC2

## Зміни
- Новий повноекранний календар місяця (старий і новий стилі).
- Збереження останньої дати й позиції на сторінці.
- Три розміри віджетів; теми віджетів синхронізовані з темами застосунку.
- Повноцінні світла й темна теми для головного екрана, календаря,
  меню та системних діалогів. Вимкнено force-dark і мерехтливі анімації.
- Векторні іконки, покращена читабельність, спільна палітра з перевіркою контрасту.
- Цілеспрямовано виправлено запис за 2 серпня старого стилю: архідиякон Стефан.
- Нормалізовано змішані латинські/кириличні літери у виведенні старого місяцеслова.
- Додано 365 архівних записів **читань 2018 року** з номером сторінки
  першоджерела. Читання інших років не підміняються вказівками 2018.
- 365 дат архіву зіставлено з 366-денним місяцесловом; алгоритмічні
  оцінки й обмеження ручної звірки зафіксовано в SOURCE_VERIFICATION_2018.md.
- UI-тести на Android-емуляторі, тести календарної арифметики та контрасту.

## Відомі обмеження
- Першоджерело 2018 року не є універсальним календарем богослужбових
  читань інших років. Неперевірені рубрики не відображаються як чинні.
- Повну текстологічну вичитку кожного святого необхідно виконати
  окремо від алгоритмічного зіставлення.
- Публічний релізний APK потребує захищених секретів постійного підпису
  GitHub Actions. Тестова debug-APK не має гарантовано однакового підпису
  між збірками.

Застосунок офлайн; Android 7+ (minSdk 24); оригінальна база calendar.json
залишилася недоторканою; це не офіційне видання УПЦ КП.

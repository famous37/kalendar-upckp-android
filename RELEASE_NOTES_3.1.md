# Календар УПЦ КП 3.1 — release candidate
- Збереження вибраного дня та позиції прокручування після закриття й повторного відкриття.
- Повноекранний офлайн-перегляд місяця з юліанською датою в кожній клітинці та позначками свят.
- Три віджети: компактний, звичайний, розширений.
- Уніфікована типографіка та контрастна світла/темна палітра.
- Регресійні тести обчислення дат і UI-тест навігації на Android-емуляторі.
- Захищений процес підпису релізу через GitHub Actions Secrets (секрети необхідно налаштувати власникові).

Версія для тестування: 3.1.0-rc1. Релігійні тексти з оригінальної бази 1.1uk не змінювалися; ці дані мають пройти окрему джерелознавчу верифікацію.

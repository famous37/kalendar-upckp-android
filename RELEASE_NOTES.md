# Церковний календар УПЦ КП 3.0 — Beta 1

Перша тестова версія повністю переписаного нативного Android-застосунку.

## Можливості
- Український церковний календар зі старим (юліанським) стилем та цивільною датою.
- 366 перенесених записів із попереднього календаря, зокрема пам'яті святих.
- Навігація за датами, календар місяця, пошук і вибрані записи.
- Темна/світла тема, налаштування розміру тексту та доступне меню.
- Віджет головного екрана.
- Робота офлайн; мінімальна версія — Android 7 (API 24).

## Завантаження
Завантажте файл `Kalendar_UPCKP_3.0_Beta1.apk` у розділі **Assets** цього релізу.

## Важливо
- **Beta / prerelease:** APK успішно скомпільовано на GitHub Actions, але роботу на фізичних пристроях і всі функції ще не перевірено.
- APK має **тестовий debug-підпис**. Для оновлення з іншої тестової APK може знадобитися видалення попередньої збірки.
- Календарні тексти перенесено з попереднього застосунку; точність річних богослужбових приписів та відповідність офіційному календарю УПЦ КП потребують додаткової перевірки.
- Це **не офіційний застосунок УПЦ КП**.

Збірка: GitHub Actions, успішний запуск №4 (run `42471016584`).

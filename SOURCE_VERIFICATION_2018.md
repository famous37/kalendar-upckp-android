# Звірка бази з виданням УПЦ КП за 2018 рік

Джерело: «Православний церковний календар на 2018 рік».
Видавниче управління Української Православної Церкви Київського Патріархату.
Головний редактор — протоієрей Олександр Трофимлюк; упорядник місяцеслова —
протоієрей Іоан Київський. PDF надано власником проєкту.

## Індекс днів та читань
- У PDF, сторінки 5–76, виділено всі **365 цивільних дат 2018 року**.
- Валідація пар дат старий/новий стиль пройшла для всієї послідовності
  від 2018-01-01 до 2018-12-31.
- Біблійні посилання індексовані для 365 днів; пропуски для 14/16 лютого
  (читання Іоїла/Захарії без маркера «зач.») виправлено за оригіналом.
- Дані зберігаються окремо від 366 нерухомих пам'ятей (calendar.json).
  Богослужбові приписи 2018 не видаються за приписи інших років.

## Перевірене виправлення
- 2 серпня старого стилю / 15 серпня 2018: первісний запис
  «архидияк;Стефана» помилково створював дві пам'яті через крапку з комою.
  Заміна на «архідиякона Стефана» підтверджена PDF (сторінка 52).
- Внесено точкову поправку через TextCorrections.java. Оригінальний
  calendar.json залишається недоторканним.

## Межі верифікації
У машинному тексті PDF окремі рядки й заголовки колонок зміщені між сусідніми
датами. Збережено source_excerpt_2018 лише для контрольної ручної звірки.
Повний витяг маркований як **автоматичний**, не як вичитаний літургійний текст.
Це не означає, що перевірено весь набір з 366 нерухомих пам'ятей.
Першоджерело не можна автоматично використовувати для визначення
рухомих читань поточного року або майбутніх років.

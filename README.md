# Календар УПЦ КП 3.0 — Android

Нативний Android-проєкт українського церковного календаря. Мінімальна версія Android 7 (API 24).

## Побудова APK

1. Завантажте у корінь цього репозиторію файл `Kalendar_UPCKP_3.0_Source_REUPLOAD.zip` (сам архів, без розпакування).
2. Відкрийте вкладку **Actions → Build Calendar APK → Run workflow**, або дочекайтеся автоматичної збірки після завантаження ZIP.
3. У результатах успішної збірки завантажте артефакт `UPCKP-debug-APK`: у ньому міститься `app-debug.apk`.

Календарні записи перенесені з наданого власником старого APK. Богослужбова точність річних приписів та відповідність офіційним виданням потребує додаткової звірки. Застосунок не є офіційним продуктом УПЦ КП.

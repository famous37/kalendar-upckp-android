# Церковний календар УПЦ КП 3.0 — Android

Нативний український церковний календар для Android 7 (API 24) та новіших версій. Працює офлайн.

## 📲 Завантажити застосунок

**[Завантажити APK — v3.0.0-beta.1](https://github.com/famous37/kalendar-upckp-android/releases/download/v3.0.0-beta.1/Kalendar_UPCKP_3.0_Beta1.apk)**

[Сторінка релізу та примітки](https://github.com/famous37/kalendar-upckp-android/releases/tag/v3.0.0-beta.1)

**Статус:** публічна тестова beta-версія, створена GitHub Actions із debug-підписом. У разі конфлікту підписів зі старішою тестовою збіркою може знадобитися її видалення перед встановленням.

## Функції

- Юліанський (старий) стиль і відповідна цивільна дата
- 366 перенесених записів пам'ятей святих
- Календар місяця, пошук, вибрані дати
- Налаштування шрифту, темна/світла тема, меню
- Віджет головного екрана

## Збирання з вихідного проєкту

Вихідний архів: `Kalendar_UPCKP_3.0_Source_2026-11-08.zip`. Автоматична збірка: **Actions → Build Calendar APK**. Для публікації Beta 1 використано успішний запуск збірки [№4](https://github.com/famous37/kalendar-upckp-android/actions/runs/42471016584).

> Увага: календарні записи перенесено з попередньої версії; точність усіх богослужбових приписів потребує окремої перевірки. Це не офіційний застосунок УПЦ КП. Рекомендовано тестування на фізичних пристроях перед широким використанням.

# Церковний календар УПЦ КП 3.1 — Android

Нативний офлайн-календар українською мовою, старий (юліанський) стиль,
відображення цивільної дати. **Android 7+ (API 24)**.

## Функції 3.1
- Детальна сторінка дня й повноекранний перегляд місяця з датами за двома стилями
- 366 незмінених записів пам'ятей святих із джерельного архіву 1.1uk
- Православна пасхалія й довідкові пости (не заміняють затверджений церковний календар)
- Пошук, вибране, надсилання дня, підтримка теми й розміру шрифту
- Відновлення відкритого дня та позиції прокручування після повернення до застосунку
- Три віджети головного екрана, адаптивна навігація й уніфіковані іконки
- Без інтернету, зовнішніх бібліотек для runtime, реклами й дозволів доступу до мережі

## Збірка й тести
Java 17, Android Gradle Plugin 8.9.2, Gradle 8.11.1, Android SDK 35.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
```

Після збирання debug APK: `app/build/outputs/apk/debug/app-debug.apk`.
CI: [Android 3.1 CI / APK](https://github.com/famous37/kalendar-upckp-android/actions).
Instrumented UI smoke tests запускаються окремо на Android-емуляторі.

## Постійний підпис
Реліз підписується лише з GitHub Actions Secrets:
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
Workflow `Secure 3.1 Release APK` не публікує APK без цих секретів.
**Не публікуйте keystore чи паролі в репозиторії.**

Примітка: версія 3.0 beta була підписана тестовим debug-ключем.
Для переходу на новий постійний релізний ключ може знадобитися видалення beta.
Надалі релізи з тим самим ключем оновлюються поверх попередніх без видалення.

# Церковний календар

Український православний календар для Android. Створено на основі календаря Української Православної Церкви Київського Патріархату (УПЦ КП).

Пам’яті Патріарха Філарета, який до останніх днів свого життя дотримувався цього церковного календаря.

**Розробник: Василь Шлемко**

## Перша бета-версія 4.0

[Завантажити APK](https://github.com/famous37/kalendar-upckp-android/releases/download/v4.0.0-beta.1/Tserkovnyi-Kalendar-4.0.0-beta.1.apk) · [Сторінка випуску](https://github.com/famous37/kalendar-upckp-android/releases/tag/v4.0.0-beta.1)

Застосунок працює офлайн на Android 7 і новіших. Бета встановлюється поруч із попереднім застосунком і має власне вибране та налаштування.

- **День.** Дата за старим стилем і відповідна цивільна дата, свята, пости, пам’ять святих, закладка та надсилання тексту дня.
- **Місяць.** Сітка з двома датами, переходом до дня, святами місяця та пасхалією на обраний рік.
- **Пошук.** Пошук за іменем святого або назвою свята, включно з рухомими святами.
- **Вибране.** Збережені дні за юліанським календарем.
- Світла, темна й системна теми, п’ять розмірів тексту та три віджети для головного екрана.

Місяцеслов охоплює 366 юліанських дат. Біблійні посилання з друкованого видання за 2018 рік відображаються для відповідних дат 2018 року.

## Збірка

JDK 17, Gradle 8.11.1, Android SDK 35.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
gradle :app:connectedDebugAndroidTest
```

Для підписаної збірки Gradle використовує `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` і `ANDROID_KEY_PASSWORD`. Ідентифікатор бета-застосунку — `com.shlemko.upckpcalendar.beta`.
